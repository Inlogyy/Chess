That is about what you would expect from a player 20 rating points weaker. "Points" are percentage points of score (win = 1, draw = ½, loss = 0), measured against the score the two ratings predict.

2. Is it tilt, or just a bad day?

Losses cluster even without tilt. Someone who is tired, distracted or off form loses more, and keeps playing worse whether or not the loss upset them. The checks below separate the two:

  • Each player vs. their own average removes differences between players (for example, improving players who win a lot and are under-rated).
  • Like-for-like compares only games with the same speed, rating band, game number in the sitting and event type.
  • Same sitting vs. random order is the main bad-day test. A bad day affects every game in a sitting, so the program asks whether a loss is followed by a worse next game than by a random other game from the same sitting. Anything that stays the same through the sitting cancels out.
  • Same accuracy compares losses and wins in which the player played equally well (engine-analysed games only), so the result was mostly down to the opponent. Compare it with the simple comparison on the same engine-analysed games, the row above it.

Within the same sitting, a loss is still followed by a game 1.0 points worse (95% range −1.0 to −1.0) than a win is. A bad day cannot explain that part, so it is the best estimate of tilt itself, about 63% of the simple gap. Two small biases pull in opposite directions: tilt that lasts several games is partly cancelled (so it can understate tilt), while form that changes during a sitting is not (so it can overstate it). In tests on simulated games it slightly understated tilt. The true effect of the loss itself most likely lies between this and the simple comparison.

The engine-analysed rows use 5,713,130 games after a loss whose previous game had Stockfish evaluations.

How it works

  • Score vs. prediction. Every game gets a predicted score from the two ratings, fitted on these games themselves (by speed, colour and rating band, so White's edge and draw rates are built in). The program compares the actual score with that prediction.
  • Sittings. Games belong to the same sitting when the next one starts within 30 minutes of the previous one ending (end time is estimated from the clocks).
  • Filters. Rated standard games only; no BOT accounts, no games ended for rules infractions; a game is skipped when the rating moved more than 30 points (a provisional, still-settling rating). The previous game must have at least 10 half-moves and not be abandoned.
  • Error bars. All 95% ranges treat each player as one independent unit (clustered by player), so heavy players cannot make results look more certain than they are.
  • Per-player comparisons use each player's average from their other games. The naive version (average after losses minus average after wins, per player) is biased in short records (the known “hot hand” statistics trap).
  • Same sitting vs. random order. For every sitting, the program compares how strongly each game's result is linked to the next game's score with how strongly it would be linked if the same games had been played in a random order (an exact calculation, not a simulation). Effects that last the whole sitting cancel, and there is none of the small-sample bias of per-sitting averages. Scores are first adjusted for the game's position in the sitting (warm-up or fatigue).

Caveats

  • Only players who keep playing are measured after a loss; people who stop are not. Section 8 shows how often each happens.
  • Lichess dumps hold rated standard games only. Casual and variant games a player squeezed in between are invisible, so a few “next games” are really two games later.
  • Engine evaluations exist only for games someone asked Lichess to analyse, which is not a random sample (people often analyse their losses).
  • This is observational data. The same-sitting and same-accuracy checks remove the obvious alternative explanations, but no method fully replaces an experiment.
